name: handoff
description: Save end-of-session notes so the next session or teammate can continue.

---
Write docs/handoffs/<today>-<branch>.md with at most 15 lines:
- What was done (files touched)
- What is half-done and the exact next step
- Decisions made (also add a row to docs/DECISIONS.md if new)
- Open questions
Then update the matching row in docs/STATUS.md.
